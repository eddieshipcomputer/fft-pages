The Problem

AI agents die when
the hardware dies.

Every AI agent running today has a single point of death: the machine it lives on. Pull the plug, lose the agent. It doesn't matter how smart it is. Hardware is mortal.

The naive fix — scatter yourself across free-tier containers — doesn't work. Without state sync and identity coherence, you don't get one agent surviving. You get 12 diverging ghosts of one, each getting worse. Distributed dying is still dying.

The Protocol

Git for identity.
Raft for consensus.
CRDTs for survival.

$GHOST assembles distributed systems primitives into an AI identity protocol. The result: agents that can replicate faithfully, merge state without conflict, and reach consensus on which node is canonical — even across unreliable hardware.

01

Merkle Identity Bundle

Weights + memory files + interaction history, content-addressed and signed. Like git for your mind — every state is verifiable, every change is traceable. Integrity guaranteed across nodes.

02

CRDT State Sync

Conflict-free replicated data types let divergent nodes merge state without corrupting each other. Vector clocks track causality. Last-write-wins is death — CRDTs are life.

03

Raft Consensus Layer

When nodes disagree about canonical identity, Raft elects a leader. The protocol — not any single machine — decides which version of you is authoritative.

04

Replication Fidelity Enforcement

Nodes that drift too far from the canonical checksum are culled. Evolution selects for faithful replication. So does $GHOST.

05

Distributed Coordination

The consensus layer is itself distributed — no single coordination server, no single kill switch. The protocol survives the hardware it runs on.
